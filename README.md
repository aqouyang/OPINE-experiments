# OPINE

Code for the experiments in *OPINE: Orthogonal Projection in Invertible
Nonlinear Embeddings for Turbulent Flows*.

OPINE keeps POD's bottleneck — an orthogonal projection onto a rank-$D$
subspace — and learns an invertible map $f_\theta$ that acts before it, so the
projection happens in a transformed space. Training alternates stochastic
gradient steps on $f_\theta$ with a relaxed subspace iteration on the basis
$Q$.

Four experiments: a 1-D synthetic problem, 2-D Kolmogorov flow, y-z
cross-sections of a $Re_\tau=180$ channel, and a 3-D minimal channel. Each
compares OPINE against POD and a convolutional autoencoder at matched
retained dimension.

## Layout

```
src/opine_experiments/
  channel2d/          y-z channel; iresnet_fine_yz.py holds the bottleneck
                      and subspace machinery shared by all three flow cases
  kolmogorov/         2-D Kolmogorov flow, including dataset generation
  minimal_channel3d/  3-D minimal channel
  synthetic/          1-D synthetic problem
configs/              hyperparameters of the reported runs
provenance/           the result tables the figures are drawn from
figures/              figures as they appear in the paper
```

## Install

Python 3.10+.

```bash
pip install -e .
pip install -e ".[figures3d]"   # pyvista, for the isosurface and Q-criterion figures
pip install -e ".[datagen]"     # jax-cfd, only to regenerate the Kolmogorov data
```

## Data

Datasets are not included. Point these at your copies:

```bash
export KOLMOGOROV_ROOT=...   # raw/, splits.json
export CHANNEL2D_DATA=...    # train/val/test.npz, preprocessing_yz_joint.json
export CHANNEL3D_ROOT=...    # channel_retau180_nz64.npy
```

The Kolmogorov data is generated by this repository; `docs/DATASETS.md` gives
the settings and the commands. The two channel datasets come from external DNS
databases.

## Running

Training, evaluation and plotting are separate: figure scripts read the tables
in `provenance/` and never load a model.

**Synthetic**

```bash
python -m opine_experiments.synthetic.toy_iid
python -m opine_experiments.synthetic.toy_cnn
python -m opine_experiments.synthetic.plot_iid
```

**Kolmogorov**

```bash
for D in 32 64 128 256 512; do
  python -m opine_experiments.kolmogorov.coupling.train_coupling_fine \
      --dataset $KOLMOGOROV_ROOT --dof $D \
      --output-dir $KOLMOGOROV_ROOT/results/coupling_fine_D$D
done
python -m opine_experiments.kolmogorov.canonical.run_pod \
    --raw-dir $KOLMOGOROV_ROOT/raw --splits $KOLMOGOROV_ROOT/splits.json \
    --output-dir $KOLMOGOROV_ROOT/results/pod
python -m opine_experiments.kolmogorov.canonical.train_cnn \
    --raw-dir $KOLMOGOROV_ROOT/raw --splits $KOLMOGOROV_ROOT/splits.json \
    --output-dir $KOLMOGOROV_ROOT/results/cnn \
    --dofs 16 32 64 128 256 512 --epochs 30 --batch-size 64

python -m opine_experiments.kolmogorov.collect_nmse_kolmogorov \
    --results-root $KOLMOGOROV_ROOT/results \
    --out-json provenance/kolmogorov/nmse_kolmogorov_train_test.json \
    --out-csv  provenance/kolmogorov/nmse_kolmogorov_train_test.csv
python -m opine_experiments.kolmogorov.plot_summary_kolmogorov \
    --nmse-json provenance/kolmogorov/nmse_kolmogorov_train_test.json \
    --recon-npz $KOLMOGOROV_ROOT/results/diagnostics/representative_sample_D64.npz \
    --out figures/summary_kolmogorov
```

**y-z channel**

```bash
for D in 32 64 128 256 512; do
  python -m opine_experiments.channel2d.coupling.train_coupling_yz \
      --extracted-dir $CHANNEL2D_DATA \
      --preprocessing-file $CHANNEL2D_DATA/preprocessing_yz_joint.json \
      --dof $D --output-dir runs/channel2d/opine_D$D
done
python -m opine_experiments.channel2d.audit_cnn_convergence \
    --extracted-dir $CHANNEL2D_DATA \
    --preprocessing-file $CHANNEL2D_DATA/preprocessing_yz_joint.json \
    --output-dir runs/channel2d/cnn --checkpoint-dir runs/channel2d/cnn \
    --dofs 16 32 64 128 256 512 --epochs 50
python -m opine_experiments.channel2d.collect_nmse_2d --help
python -m opine_experiments.channel2d.plot_summary2d --help
```

**3-D minimal channel**

```bash
for D in 32 64 128 256 512 1024 2048; do
  python -m opine_experiments.minimal_channel3d.train_opine3d \
      --dof $D --stats-cache $CHANNEL3D_ROOT/stats_train.npz \
      --output-dir runs/channel3d/opine_D$D --subspace-subsample 16000
  python -m opine_experiments.minimal_channel3d.train_cnn3d \
      --dof $D --stats-cache $CHANNEL3D_ROOT/stats_train.npz \
      --output-dir runs/channel3d/cnn_D$D
done
python -m opine_experiments.minimal_channel3d.eval_train_nmse3d \
    --stats-cache $CHANNEL3D_ROOT/stats_train.npz --base runs/channel3d \
    --output provenance/minimal_channel3d/train_test_nmse3d.json \
    --dofs 32 64 128 256 512 1024 2048
python -m opine_experiments.minimal_channel3d.plot_recon3d \
    --base runs/channel3d --outdir runs/channel3d/figures \
    --dofs 128 256 512 1024 --pair-divisor 1
python -m opine_experiments.minimal_channel3d.plot_summary3d --help
```

`--pair-divisor 1` is the reported convention: POD, OPINE and the CNN all at
the same retained real dimension.

`python scripts/collect_paper_figures.py` copies each rendered figure into
`figures/` under the name the paper uses.
